# Simple User Management System
## Description
A simple but powerful user management application built with the MERN stack. Users can be added, viewed, updated, and deleted. The frontend reflects real-time changes without needing page reloads, and all UI components are custom-built from scratch.

## Features

- 🔄 Full CRUD operations for users

- 🌐 RESTful APIs built with Express.js

- ⚛️ Instant UI updates with React state management (no reloads)

- 🧰 Custom-built modal component with no UI libraries

- 📦 MongoDB for data storage

- 💅 Tailwind CSS for styling
## Tech Stack
- **Frontend:** React.js + Tailwind CSS  
- **Backend:** Express.js + Node.js  
- **Database:** MongoDB  
- **API Communication:** Axios  
- **State Management:** useState + useEffect
- **Deployment:** Both Client and Server side are hosted in Vercel
